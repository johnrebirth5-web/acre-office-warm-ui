# Listing Studio Extension Store Listing

## Canonical extension name

`Acre Listing Studio`

## Category

- `Productivity`

## Short description

Use Acre Listing Studio to save StreetEasy and Zillow listings directly into Acre for sharing, editing, and PDF export.

## Long description

`Acre Listing Studio` helps real estate professionals capture supported listing pages and turn them into client-ready packets inside Acre.

With the extension installed, supported StreetEasy and Zillow listing detail pages show an Acre save card. From there, the user can:

- save the current listing directly into Acre Listing Studio
- capture listing facts, media, and key source sections
- open the saved packet in Acre
- edit the client-facing copy
- publish a share page
- export a PDF

The extension only works on supported listing pages and only sends data to Acre after the user connects the extension and actively chooses to save a listing.
