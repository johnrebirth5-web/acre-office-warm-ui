# Code of Conduct

## Our Pledge

We want Acre to be a welcoming project for people building real estate operations tools. Contributors, maintainers, and users are expected to participate respectfully and constructively.

## Expected Behavior

- Be respectful and considerate.
- Assume good intent while staying clear about technical concerns.
- Keep feedback specific, actionable, and focused on the work.
- Welcome newcomers and help them understand project context.
- Respect privacy and do not share private operational details, credentials, or sensitive data.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Personal attacks or sustained disruptive behavior.
- Publishing private information without permission.
- Sharing credentials, tokens, secrets, exploit details, or sensitive user data in public project spaces.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code of conduct. Repeated or severe violations may result in a temporary or permanent ban from project participation.

## Reporting

If you see behavior that violates this code of conduct, contact the maintainer through the safest available GitHub channel. Do not include private personal information or security-sensitive details in public issues.
