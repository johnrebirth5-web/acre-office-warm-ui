# Changelog

All notable public-facing changes to this project should be documented here.

This project follows a simple, human-readable changelog format. It does not currently claim semantic versioning stability.

## Unreleased

### Added

- Open-source README positioning for Acre as a real estate brokerage operations workspace and listing workflow toolkit.
- MIT license.
- Contributor guide, security policy, code of conduct, roadmap, issue templates, and pull request template.
- Safe `.env.example` placeholders for local development.
- Good first issue guidance for new contributors.

### Changed

- Public documentation is being generalized away from private deployment notes and internal operational assumptions.

### Security

- Public docs and examples should avoid private IP addresses, production paths, service names, domains, and secret-like values.
